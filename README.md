# 🎓 Bright Future Academy

## 📖 Project Overview

Bright Future Academy is a responsive educational website developed using HTML, CSS, and JavaScript. The website provides information about the academy, available courses, faculty, gallery, and contact details. It also includes a student registration form with JavaScript validation.

---

## ✨ Features

- 🏠 Home Page
- 📘 About Us
- 📚 Courses
- 👨‍🏫 Faculty Information
- 📅 Timetable
- 📖 Study Materials
- 🖼️ Gallery
- 📞 Contact Page
- 📝 Student Registration Form
- ✅ Form Validation using JavaScript
- 📱 Responsive Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension (if not already installed).
4. Right-click **index.html** and select **Open with Live Server**.
5. Explore the website using the navigation menu.
